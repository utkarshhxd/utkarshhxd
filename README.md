## 🧑‍💻 About Me

> *"Write code that a junior dev can read, and systems that a senior dev respects."*

I'm a **Backend Developer** who cares deeply about **System Design**, **distributed architecture**, and writing production-grade code. I build things that are meant to scale — from event-driven notification services to real-time collaboration tools.

- 🔭 Currently exploring **distributed systems** and **microservices patterns**
- 🧠 Learning **advanced system design** — caching, queuing, sharding
- 🛠️ Always building: check my **[System Design Playground](https://github.com/utkarshhxd/System-Design-Playground)**
- 🤝 Open to **collaborating** on backend/open source projects
- ⚡ Fun fact: I think in **flows and diagrams** before I write a single line
